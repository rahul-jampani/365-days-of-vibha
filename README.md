# 365 Days of Vibha

Static interactive dashboard ready for GitHub Pages.

## Publish on GitHub Pages
1. Upload `index.html` and the `images` folder to your repository root.
2. Go to **Settings → Pages**.
3. Choose **Deploy from a branch**.
4. Select `main` and `/ (root)`.
5. Save.

Your site will be available at:
`https://YOUR-USERNAME.github.io/365-days-of-vibha/`
